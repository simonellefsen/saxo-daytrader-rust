# Runbooks

Operational procedures belong here when they should survive a chat session.

Examples:

- Kubernetes deployment and rollback checks.
- CloudNativePG backup and restore procedures.
- ngrok endpoint verification.
- qmd index maintenance.
- Obsidian vault checks.
- Saxo session recovery procedures that do not expose secrets.
