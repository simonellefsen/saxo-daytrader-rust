# Experiments

Hermes and strategy experiment notes belong here.

Each experiment should record:

- Baseline.
- Goal contract version.
- Exactly one changed variable when `one_variable_only` is true.
- Hypothesis.
- Evidence.
- Metrics.
- Approval, rejection, rollback, or promotion status.
